## 🧠 Hindsight

IncidentMind uses Hindsight to provide persistent organizational memory across the complete incident lifecycle:

**RECALL → REFLECT → REASON → HUMAN REVIEW → RESOLVE → RETAIN**

Past incidents become operational experience that can support future incident investigation.
